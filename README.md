A selection of hardware components commonly used in my DIY electronics projects.

## Usage

In KiCAD, add the following Path to your Library Table, under "Preferences" -> "Configure Paths":

| Name    | Path                    |
|---------|-------------------------|
| HW_COMP | Path to this repository |

Then, you can access the components in your schematic and PCB designs
after adding the corresponding libraries to your project.
